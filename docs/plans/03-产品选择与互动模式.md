# 已确认的产品选择与互动模式

确认日期：2026-10-20。状态：已有 P00 动态原型；本文件中的三种互动模式和正式角色设置尚未实现。返回[计划总览](README.md)。

## 1. 已确认的五项选择

| 事项 | 当前决定 | 对计划的影响 |
|---|---|---|
| 平台与用途 | 先做 Windows，主要用于个人自用 | 首版集中验证 Windows，不承担跨平台和商业发行工作 |
| 角色与素材 | 二维二次元／卡通方向；目前没有可用动态模型和动作 | P00 增加验证素材准备，明确占位资源与正式角色的区别 |
| 语音 | 后续更新再添加；暂无语音文件和内容 | 首版使用文字与动作，不要求录音、音色、语音服务或口型联动 |
| AI 来源与费用 | 本地 AI 后续更新；云端 AI 暂不设置预算，测试时再确认 | 首版支持无 AI 或可选云端 AI；预算为空是正常状态 |
| 主动互动 | 安静陪伴、偶尔问候、较丰富养成作为可选模式 | P01 提供可切换模式及本地行为差异，P06 回归验证 |

以上替代早期文档中对应的待确认项。P00 测试角色与实际动作见[素材清单](../assets.md)，框架见[技术决策](../architecture/P00-decisions.md)。正式角色形象和模型供应商仍待后续确定。

## 2. 素材准备路线

当前不假定用户已有原画、分层文件、绑定模型、动作或语音。暂定实施顺序：

1. P00 先用简单二维占位资源验证透明窗口、拖动、点击和界面布局；这不代表最终角色效果。
2. 为候选动态渲染方案准备适合测试的模型或动画资源，记录来源、格式与可用动作。Live2D 专项验收需要真实可运行的模型，不能由静态占位替代。
3. 确定正式角色获取／制作方式，再拆分原画、分层、绑定和动作制作工作。没有选定来源前，不默认采购或承诺已有原创模型。
4. 初期动作目标可包括待机、点击反馈、问候、思考和开心；只有素材实际支持的动作才向 Agent 暴露，缺失部分明确记录。

二维角色方向已确定，是否采用 Live2D 或序列帧仍以验证结果为准。语音素材与口型所需资源不计入首版验收。

## 3. 互动模式的首版范围

下面是基于用户选择形成的初版行为设计，具体频率与数值在体验测试时调整。

| 模式 | 角色表现 | 主动行为 | 用户主动操作 |
|---|---|---|---|
| 安静陪伴 | 呼吸、眨眼和低干扰待机 | 不主动发闲聊气泡 | 点击、拖动、打开聊天等照常响应 |
| 偶尔问候 | 基础动画和低频问候动作 | 在允许时段按事件／间隔触发简短问候，有冷却 | 正常响应，并避免重复问候 |
| 丰富养成 | 更丰富的本地事件反馈和可查看的轻量互动状态 | 可选问候、每日互动事件和轻量成长反馈 | 可触发更多已支持的动作与互动，记录必要状态 |

三个模式在 P01 提供可实际使用的入口。“丰富养成”首版做到本地事件、互动计数或轻量状态及对应反馈；后续再扩展复杂好感度、收集或剧情等内容，不用一个空开关冒充已实现的模式。

建议首次使用默认“安静陪伴”，并允许即时切换；这是设计建议，用户尚未指定默认值。角色性格决定表达方式，互动模式决定主动程度，二者分开保存，不通过切换模式改写人物背景。

## 4. 设置与运行规则

- 保存模式、允许互动时段、主动问候开关、问候间隔和冷却，以及轻量互动状态；重启后恢复。
- 免打扰优先于主动问候与养成事件。用户手动创建的到期提醒使用独立通知策略，不因切成安静模式被静默取消。
- 切换到更安静的模式时，撤销尚未呈现的主动事件；退出免打扰不补发积压问候。
- 本地动画、预设台词和养成状态无需模型即可运行。选择丰富模式不会自动打开云端 AI、持续查看或语音。
- 首版主动问候采用本地内容；如果后续加入 AI 生成主动台词，应另设明确开关和频率，不随模式自动产生后台 API 请求。
- 关闭养成模式不删除已有状态；提供明确的重置入口。用户离线不触发惩罚或催促。

## 5. 云端 AI 的预算状态

当前预算值为“未设置”，不自动填入上限，也不把它解释为零费用。首次接入无需先填写预算。

P02 开始实际联调时记录模型、调用次数、供应商提供的用量和已知价格下的费用估算，再根据体验和使用量确认是否设置额度。价格未知时显示未知，不编造账单。

P03 的预算限制为可选设置，只有用户明确填写并启用后才参与路由或拦截。超时、重试次数、任务步数和采集频率属于运行控制，即使未设置金额上限也仍有效。

语音与本地 AI 明确进入后续更新，不属于当前 Windows 首版安装、启动或验收的条件。
