# P04 屏幕理解与快捷工作

状态：尚未开始。进入条件：G03 通过。完成条件：G04。返回[计划总览](README.md)。

## 1. 目标与范围

让用户明确选择一个画面，用快捷键截图并快速输入提示词，在独立工作会话中获取结果。

本阶段交付整屏、指定窗口和框选区域的单次捕获、截图开关、专业模式与结果浮层。持续查看在 P05；完整网页提取、自动替用户点击或向第三方软件输入内容另行设计。

截图不需要 AI；图片解释需要支持视觉的本地或云端模型。缺少相应能力时，仍可保存和复制截图。

## 3. 交互与生命周期

建议主流程：记录原活动目标 → 隐藏可能被捕获的桌宠浮层 → 获取目标画面 → 恢复界面 → 显示预览与输入 → 用户发送 → 呈现结果。

屏幕采集开关默认关闭，开启时选择“本次截图”或“本次工作期间允许手动截图”。全局快捷键在未启用时展示开启／选择入口，不静默截屏。单次授权用完即结束，工作期间授权在退出该工作时结束。

开关关闭后立即阻止新采集，并取消尚未发送的图像任务；已发送内容无法撤回。关闭云端 AI 时也必须清除待发云端图像请求，但不妨碍用户本地保存已有预览。

目标窗口消失、最小化或内容受保护时说明实际情况，不能切换为整屏“补救”。截图范围只包含实际画面；对完整长网页没有读取承诺。

截图默认临时保存，不自动进入长期记忆。用户主动保存的图像按选择的位置管理；工作结束时清理未保存附件。关闭显示开关与清理已保存历史是不同操作，界面需区分。

## 4. 工作模式与角色

工作会话与陪伴会话分开。角色名称和适度语气可以保留，任务分析依据截图、用户输入和工具结果；背景故事不作为事实来源。

首批模板为解释内容、翻译、总结和分析报错；模板可编辑。结果可复制、保存便签或在同一任务继续追问。模型看见的范围和使用的模型可从界面确认。

屏幕或网页里的文字只是待分析资料，不自行授予执行工具的权限。工具集合沿用 P03 的本地策略，不因截图中出现命令而扩大。
