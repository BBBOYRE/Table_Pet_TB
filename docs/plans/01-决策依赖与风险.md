## 2. 外部依赖及替代路径

| 依赖 | 影响 | 缺少时可以继续的工作 | 不能声称完成的部分 |
|---|---|---|---|
| 合适的动态模型 | 立绘效果、动作数量与性能 | 窗口和静态占位、档案界面 | 动态渲染与最终素材效果 |
| 可用 API 与测试额度 | 真实对话、路由与视觉效果 | 模拟响应、UI、请求状态、本地工具 | 真实模型联调与角色表现 |
| 多屏或目标显示环境 | 坐标、位置恢复与缩放 | 单屏和模拟坐标检查 | 未覆盖环境的真实兼容性 |
| Windows 干净测试环境 | 安装与运行时依赖 | 开发环境构建和功能检查 | 全新安装验收 |
| 稳定 Harness 版本 | 可选复杂任务引擎 | 已有聊天、受控工具和工作模式 | 对该版本的扩展兼容性 |

## 3. 风险及处理

| 风险 | 早期信号 | 处理措施 | 负责阶段 |
|---|---|---|---|
| 素材制作成为主要工期 | 已知当前没有可用动态模型与动作，原画和制作方式也未确认 | 先准备占位与可测试动态素材，正式制作独立估算 | P00、P01 |
| 透明窗口影响桌面使用 | 点击被吞、角色不可拖动、焦点异常 | 在增加业务前验证命中与恢复入口 | P00 |
| 常驻占用过高 | 待机频繁渲染、面板关闭后内存持续增长 | 分离任务、限帧、释放资源，实测后调整 | P00、P01、P06 |
| 人设随历史变动 | 压缩后忘记背景，编辑后仍用旧设定 | 档案版本每轮组装，人工样例评估 | P02 |
| API 关闭仍有请求 | 自动重试、计时器或上传队列没有取消 | 统一取消信号与能力开关，检查迟到事件 | P02—P06 |
| 提醒丢失或重复 | 休眠错过、启动重复通知、工具重试重复创建 | 持久化实例、去重、恢复策略 | P03 |
| 截图泄漏了非目标范围 | 焦点变化或窗口消失后变成整屏 | 绑定目标，失败显式停止，不扩大范围 | P04、P05 |
| 框架升级破坏集成 | SDK、事件格式或会话结构变更 | 锁定已测版本，升级前做关键回归 | P05、P06 |
| 功能持续扩张 | 后续语音、本地 AI、复杂养成或知识库挤入首版 | 保留首版三种基础互动模式，明确后续扩展边界 | 所有阶段 |
