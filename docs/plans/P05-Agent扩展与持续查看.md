# P05 Agent 扩展与持续查看

状态：尚未开始；按需启用的增强阶段。进入条件：G04 通过。完成条件：G05，仅适用于明确纳入的模块。返回[计划总览](README.md)。

## 1. 目标与范围

为多步骤工作提供可替换的运行引擎，并在用户启用时允许限定目标、限定时间的持续查看。基础版本可先直接进入 P06，不依赖本阶段上线。

两个增强模块可以分别选择：A 为 Agent 工作引擎，B 为持续查看。未实施的模块标记“未纳入”，不能当作已验收；如果两个都不实施，本阶段保持未纳入状态。

DeepSeek Harness 是优先验证候选，具体版本与 SDK 接口需要在实施时复核。它不是模型，也不是桌宠宿主或基础动画系统。

## 3. 模块 A：工作引擎约定

桌宠宿主管理可选后台进程的生命周期，使用受限接口或经过鉴权的本地通道。API 未启用且未配置本地推理时不启动引擎。

接入时明确模型调用、备用切换和重试的唯一负责方：若由 Harness 管理，桌宠适配器同步配置并接收结果；不允许两层分别重试造成重复副作用。

工具从 P03 的本地服务注册，按任务开放。代表任务可为“在获准范围内分析选定画面，将结果保存为便签并创建用户指定的提醒”，验收真实工具状态，而非只看总结文本。

任务状态至少包含等待、运行、取消中、完成、失败、已取消和结果待确认。用户停止后不再调度新步骤；已经提交给外部系统的动作可能完成，需要如实显示，不能声称全部撤销。

引擎崩溃时保留已有事件和工具结果，恢复前确认未决动作的实际状态。无法确定是否已执行的动作不自动重放。

## 4. 模块 B：持续查看约定

在 P04 之外独立增加持续查看开关。用户明确选择目标、用途和时长，界面持续显示状态，退出工作、到期、目标关闭或用户关闭开关后停止。

限制采集频率，并对变化检测后的图像设置上传频率和预算上限；稳定画面不反复请求模型。第一版参数在技术验证后确定，不以每秒调用模型作为默认实现。

权限缩小或失效时清除排队图像，不扩大为全桌面，也不跟随任意新前台窗口。关闭云端 AI 时停止发往云端的查看任务；本地模型仅在用户明确启用时可承接。

## 5. 验收场景

- [ ] **P05-A01 / 模块 A**：代表任务通过真实工具完成并显示过程；有限步数、超时和费用限制生效，工具结果与最终报告一致。
- [ ] **P05-A02 / 模块 A**：运行中取消与模拟进程崩溃后，没有新步骤启动；重复请求不重复建提醒；状态不明的外部操作不会被直接重放。
- [ ] **P05-A03 / R07、模块 B**：持续查看仅采集所选目标，状态可见；稳定画面不重复上传；到期、目标关闭、撤销和退出工作均停止采集与待发请求。
- [ ] **P05-A04 / 模块 A、B**：仅对纳入模块执行对应检查；关闭扩展后进程／计时器／订阅释放，基础桌宠、提醒与普通聊天仍正常。
- [ ] **P05-A05 / 模块 A**：固定版本重新安装后能够复现接入；升级候选版本通过流式事件、工具、取消与数据兼容检查后再替换。
