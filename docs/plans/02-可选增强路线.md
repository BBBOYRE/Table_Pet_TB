## 1. 本地模型的边界

“不使用云端 API”可以是纯基础桌宠，也可以是用户额外启用本地 AI。两者不能混为一个必装方案。

本地模型通过 localhost 服务或嵌入式运行时工作均可，但必须按硬件评估。文本模型不自动具备视觉或工具能力；不兼容时说明限制，不静默转向云端。首次模型下载由用户主动触发。

## 2. 语音和角色扩展的边界

语音服务按自身来源决定是否需网络；关闭 AI 不应留下未经选择的云端音频调用。口型联动取决于角色模型是否支持相应参数。

多角色切换默认隔离角色故事和会话；用户偏好是否共享应有明确选择。角色模板或皮肤导入不包含 API 凭据，也不自行增加系统权限。

## 3. 增强项完成标准

每项增强至少定义一个从入口到结果的实际场景，检查未启用时没有额外后台任务，失败时基础桌宠仍可运行，并补充原有阶段的回归场景。扩展不能破坏 API 可选和自定义人设两项基础要求。
