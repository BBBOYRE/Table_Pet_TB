## 1. 目标与范围

交付提醒、便签、关联提醒和快捷打开软件，让它们同时支持无 AI 的界面入口与启用 AI 后的对话调用。提供多个 API 配置、手动选择和显式启用的规则自动选择。

应用启动仅覆盖已配置路径、受支持协议和网页地址；不包含任意软件界面控制。提醒以程序运行／托盘驻留为基础，完全退出后的系统后台调度另列可选增强。

## 3. 提醒与便签约定

提醒记录包含标题、到期时间、时区、重复规则、状态和可选便签标识。时区从用户设置取值，初始可采用用户所在地，不使用开发电脑时区偷偷替换。第一版重复规则保持明确，不做任意自然语言日历系统。

每个到期实例有独立标识，通过本地事务记录处理状态，防止应用重启、系统时间回退或模型重试造成重复通知。自然语言不明确的日期要澄清，创建成功始终显示实际时间。

休眠恢复后将错过的提醒汇总呈现一次，用户可完成或稍后；不重复弹出所有历史实例。完全退出时不承诺准点提醒，重启后恢复记录并处理遗漏。

便签可以单独存在，也可以关联提醒；删除带提醒的便签时明确提示关联影响。建议默认同步取消该关联提醒，操作结果可见，避免留下用户找不到来源的通知。

## 4. 工具与路由约定

界面按钮与模型调用复用相同本地业务服务。模型不能直接拼接任意 shell 命令；打开 B 站可配置为网页，客户端路径不存在时说明问题。

创建提醒／便签等写入操作使用请求标识去重；启动外部应用若结果不明确，显示状态不明并提供检查入口，不盲目重试。工具有执行结果后，助手才报告完成。

模型配置记录供应商、地址、模型、能力、用途、可选费用设置和凭据引用。用户可以手动选定模型；自动模式只在已启用集合内，根据文本／工具／视觉能力和延迟偏好选择；只有用户设置并启用预算限制时才加入金额约束。视觉能力在 P04 实际联调后才能标记为已验证。

当前预算为“未设置”，不自动填写默认金额，也不因留空阻断接入。测试时收集用量与可获得的费用估算，再确认是否启用预算。未设置金额上限不改变请求超时、有限重试和任务步数限制。

备用切换明确显示；不突破已启用供应商范围、用户设置的费用限制或固定模型选择。本地 AI 留待后续版本接入。价格估算来源与日期可见，不能当作正式账单；无价格信息时显示未知，不显示零费用。

## 5. 验收场景

- [ ] **P03-A01 / R06**：无 API 时通过表单创建提醒，应用在托盘运行时按时触发；可以完成、稍后和取消。
- [ ] **P03-A02 / R06**：重启、休眠恢复、时间前跳和回退后，提醒恢复且同一实例不重复通知；重复规则计算正确。时间计算可用可控时钟验证。
- [ ] **P03-A03 / R06**：无 AI 时编辑、搜索和置顶便签；关联提醒正常触发；删除便签后的提醒处理符合界面说明。
- [ ] **P03-A04 / R06**：对话创建提醒或便签后返回实际记录；模拟重复工具请求只产生一份记录；模糊日期没有被悄悄猜成另一时间。
- [ ] **P03-A05 / R03**：按钮和对话均能打开已配置浏览器或 B 站目标；缺失路径、错误协议和无效目标有明确反馈。
- [ ] **P03-A06 / R02、C10**：手动切换至少两份可用配置；自动路由遵循允许集合和能力；失败备用切换可见；未设置预算时可正常使用，明确设置的预算限制有效；固定模型和禁用云端同样有效。
- [ ] **P03-A07 / R09**：切换供应商／模型后仍使用相同角色档案，会话和偏好不丢失；检查实际发送设定，另记录表现差异。
- [ ] **P03-A08 / R01**：关闭 AI 后，提醒、便签与打开软件的界面入口继续可用；路由器不会自行重新启用云端。
