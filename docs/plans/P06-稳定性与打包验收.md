## 1. 目标与范围

把已完成能力整理为可安装、可长期运行、可恢复数据的本地版本。前面各阶段持续验证功能，本阶段重点处理跨模块、打包环境和版本迁移问题。

版本范围以 P00—P04 的已确认要求为基础，加上明确选择且通过验证的扩展。本阶段生成 Windows 个人自用的本地安装产物和使用文档，保留三种互动模式；语音和本地 AI 不纳入当前首版。公开分发、应用商店或商业发行不在本次范围。

## 3. 打包与数据约定

安装产物不包含开发机凭据、真实会话或私有截图。若采用依赖系统运行时的方案，应检查其存在或给出明确安装说明，不要求最终用户配置开发环境。

数据存储与应用安装目录分离。升级前备份需要迁移的数据；迁移失败保留原数据并说明恢复方式。旧程序面对不支持的新数据格式，应拒绝写入，不能继续运行并损坏数据。

导出默认不包含 API Key。导入应校验格式、版本、角色／便签标识和提醒重复项；恢复后的提醒不得因重放历史再次成批触发。截图及会话是否导出由用户明确选择。

卸载时对是否保留用户数据作出清楚说明，不能将普通升级当作清空配置。公开分发如需额外签名、许可或渠道工作，另列任务和投入。

## 4. 验收场景

- [ ] **P06-A01 / R01**：干净的受支持 Windows 环境安装后，在无 API Key、无模型、断网条件下进入基础桌宠；已交付的本地工具正常。
- [ ] **P06-A02 / R02—R10**：用安装后的程序复核需求映射中的关键场景，包括真实 API 对话、人设、动作、三种互动模式、提醒、应用启动和快捷截图；模式设置重启后保留，首版不要求语音文件或本地模型。
- [ ] **P06-A03**：设置、角色档案、提醒和便签备份后可恢复；版本迁移失败可回到完整原数据；恢复没有重复提醒或丢失关联。
- [ ] **P06-A04**：至少 4 小时混合运行，包含待机、聊天、窗口开关与本地工具；按 P00 方法记录资源变化。对重复操作的资源增长有解释或修复，符合已锁定预算。
- [ ] **P06-A05**：断网恢复、睡眠唤醒、显示器变化、快捷键冲突和进程异常下有可理解反馈；不出现无法退出的透明窗口。
- [ ] **P06-A06**：云端 AI、屏幕采集、持续查看（如纳入）分别关闭后，无新相关任务，进程／定时器按约定释放；待发截图不会迟到上传。
- [ ] **P06-A07**：安装包和导出文件不含凭据或开发机资料；纳入分发的角色、动作、SDK 和组件有记录的许可依据与必要声明。
- [ ] **P06-A08**：用户按使用说明可完成直接使用、可选 API 设置、性格背景编辑、提醒与快捷截图；错误入口能引导到实际可执行的恢复方法。
