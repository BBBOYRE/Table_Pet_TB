# P01 无 API 桌宠基础版

状态：尚未开始。进入条件：G00 通过。完成条件：G01。返回[计划总览](README.md)。

## 1. 目标与范围

交付可独立使用的基础桌宠：用户不填写 API Key、不注册账号、不安装模型，也能看到自然待机和交互动作，并编辑角色档案。

包含二维立绘、预设台词、点击拖动、气泡、设置、角色档案、本地偏好、三种互动模式和免打扰。提醒、便签和应用启动在 P03 交付；开放式聊天在 P02 启用，不能在本阶段用随机台词冒充 AI。语音和本地 AI 不纳入首版。

## 3. 数据与行为约定

角色档案至少包含 `id`、版本、名称、自称、对用户称呼、性格、背景、关系、说话方式、对话示例和更新时间。与立绘资源、API 凭据和未来会话分别保存。

基础模式可使用名称和称呼替换预设台词；自由背景只保存，不自动获得推理或自由对话能力。默认示例必须能够被用户完整编辑。

动画优先处理用户拖动与点击，再处理主动互动，空闲时回到待机。动作不能无限排队；缺失动作与异常参数有确定的回退。免打扰暂停主动气泡和养成事件，用户主动点击仍可响应；首版不包含语音。

模式与人物性格分开保存：安静模式不主动闲聊；问候模式低频触发；丰富养成模式提供更多本地事件、轻量互动状态及对应反馈。复杂好感度、收集和剧情后续扩展，三种首版模式不能只有空入口。详见[互动模式设计](03-产品选择与互动模式.md)。

切换到更安静的模式时取消待呈现的主动事件，不清空角色或养成状态；主动互动使用本地内容，不自动调用云端。后续的用户提醒使用独立通知策略，不因安静模式而被取消。

首次启动直接进入桌宠，并提供可稍后打开的设置入口。模型服务在该阶段没有初始化前提，不执行模型下载或 AI 网络请求。

## 4. 验收场景

- [ ] **P01-A01 / R01**：空配置、无网络、无本地模型的环境中可启动、拖动、点击并退出；没有要求填写凭据的阻断页面，也没有模型请求。
- [ ] **P01-A02 / R05**：连续点击和拖动时动作不会失控排队；无效／缺失动作回到可用状态；动画和透明区交互符合 P00 约定。
- [ ] **P01-A03 / R09**：编辑性格、背景与称呼后保存，重启仍在；放弃未保存更改与恢复默认的行为清晰，不无声覆盖用户档案。
- [ ] **P01-A04**：开启免打扰并触发时段事件，不出现主动打扰；关闭后按冷却规则恢复，不补发成串问候。
- [ ] **P01-A05**：移动角色、改变屏幕布局并重启，角色仍可见；偏好和位置保存可恢复。
- [ ] **P01-A06**：持续运行至少 1 小时并重复打开设置面板，资源释放与已设性能预算符合预期；异常日志足够定位问题。
- [ ] **P01-A07 / R10**：使用相同事件序列检查三种模式的实际差异；切换、免打扰和重启后规则与状态正确，安静模式无主动闲聊，退出免打扰不补发积压事件；全程不需要模型或语音。
