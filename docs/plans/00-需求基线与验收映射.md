# 需求基线与验收映射

日期：2026-10-20。状态：计划基线，功能尚未实现。

返回[计划总览](README.md)。需求描述来自项目初始需求与已确认的补充要求；实现方式与阶段拆分属于建议方案。

## 1. 已确认需求

| 编号 | 用户要求 | 负责阶段 | 最低可验证结果 |
|---|---|---|---|
| R01 | API 接入可选 | P01、P02；P06 回归 | 无凭据、无模型时可进入桌宠；关闭 AI 后本地功能继续运行 |
| R02 | 接入 API，并自主选择 API | P02 基础接入、P03 多模型选择 | 可自行配置与选择；启用自动选择时只在允许集合内按能力路由 |
| R03 | 打开指定软件，如浏览器、B 站 | P03 | 按钮和对话可启动已配置目标；没有客户端时使用已配置网页入口 |
| R04 | 智能对话，普通聊天与专业模式 | P02、P04 | 角色聊天可流式进行；工作会话独立，模式切换不混入无关上下文 |
| R05 | 动态立绘，动作能由 Agent 调用 | P00、P01、P02 | 基础动作离线运行；模型可请求有效语义动作；无效动作不破坏待机 |
| R06 | 定时提醒、便签提醒 | P03 | 手动和对话可创建提醒；便签能关联到期提醒；重启恢复和到期去重可验证 |
| R07 | 可开关地查看桌面或指定页面 | P04；P05 增强 | 显式选择整屏、窗口或区域，关闭采集后无新捕获；理解画面需支持视觉的模型 |
| R08 | 工作模式快捷键截图与快速提示词 | P04 | 捕获目标后快速输入，返回结果可复制／保存；无 AI 时仍可截图 |
| R09 | 使用 API 时自定义人物性格与背景 | P01 编辑保存、P02 智能表现 | 可编辑档案，下一轮生效；重启、关闭 AI 和切换模型不丢失档案 |
| R10 | 主动互动可选安静陪伴、偶尔问候或丰富养成 | P01；P06 回归 | 三个模式有实际行为差异，可切换并持久化；无 AI 时均可使用 |

“自主选择 API”同时覆盖用户手动选择和前期构思中建议的规则自动选择；自动选择必须由用户启用。默认不自行添加供应商。

DeepSeek Harness 是用户提出的候选方案；“支持专业工作”不等于必须绑定该框架。P05 验证后决定是否采用，基础对话与工具能力保持独立。

## 2. 全阶段约束

| 编号 | 约束 | 检查位置 |
|---|---|---|
| C01 | 陪伴体验和动态立绘优先 | P00—P02，阶段范围评审 |
| C02 | 无 AI 时有完整的已交付本地功能入口 | P01—P06，空配置与断网检查 |
| C03 | 性格、背景、用户记忆、模型配置分别管理 | P01 数据结构、P02 请求组装、P06 数据迁移 |
| C04 | 不将预设台词描述为开放式智能理解 | P01 界面与互动说明 |
| C05 | 关闭云端 AI 后不再启动新云端请求 | P02 请求生命周期、P03 路由、P04 截图队列 |
| C06 | 模型请求经过本地参数与权限检查后才能调用工具 | P02 动作、P03 工具、P05 扩展 |
| C07 | 截图范围和开关独立于模型开关 | P04、P05 |
| C08 | 角色设定不覆盖真实任务资料或凭空增加动画能力 | P02、P04 |
| C09 | Windows 个人自用、二维角色；语音和本地 AI 不纳入首版 | P00 素材与环境、P06 范围验收 |
| C10 | 云端预算当前未设置，不要求填写后才能接入 | P02 接入、P03 可选预算与路由 |

关闭云端 AI 不等同于禁止用户主动访问网页。无 API 不等同于已具备本地模型；本地推理另列可选增强。

## 4. 已确认边界与待验证事项

Windows 首发、主要个人自用和二维二次元／卡通方向已经确认；当前没有可用动态模型与动作。语音与本地 AI 明确后续更新，云端预算当前不设上限数值，测试时再确认。三种互动模式为首版要求，复杂养成系统仍可后续扩展，详见[产品选择与互动模式](03-产品选择与互动模式.md)。

Electron、Live2D、正式角色的获取／制作方式、目标安装体积和性能指标仍需验证。跨平台、商业发行、唤醒词、完整网页提取和知识库不属于当前首版要求，详见[可选增强路线](02-可选增强路线.md)。

会话记录、基础记忆管理、免打扰与数据备份属于支撑体验的建议实现，已在阶段计划中注明范围；它们不应无限扩张成知识库或社交系统。
