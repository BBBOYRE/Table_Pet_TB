## 已有动作

| 语义 | 实际表现 | 时长 |
|---|---|---|
| `idle` | 呼吸、眨眼、头顶嫩芽摆动 | 循环 |
| `greet` | 挥手与预设问候气泡 | 约 2.4 秒后待机 |
| `happy` | 跳跃与星光 | 约 2.4 秒后待机 |
| `thinking` | 歪头与问号 | 约 4.2 秒后待机 |

气泡都是本地预设，不具备开放式理解能力。关闭气泡不停止动作。

## 正式角色路线与缺口

1. 确认正式角色外观与动作要求，可继续使用矢量动画或选择分层模型。
2. 若采用 Live2D，需有可授权的分层原画、绑定、动作、模型文件与 SDK；单独验证透明混合、命中、性能和许可。
3. 新素材先列出真实动作与失败回退，再接入动作契约；不可在没有素材时显示“已支持”。
4. 获取或制作正式素材的成本尚未确定，本阶段没有购买、委托制作或承诺已具备正式模型。
5. 语音、口型、多角色与服装系统留待后续，不是 P00／P01 的启动条件。
